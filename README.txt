Ahmad Shahid portfolio

index.html      page markup
css/style.css   all styles
js/intro.js     page-load intro animation
js/main.js      project data, galleries, scroll reveal, video reels, lightbox, nav hiding
js/ribbon.js    curved WebGL project gallery (three.js loads from the CDN link in index.html)
img/            project images
video/          reel clips

To run: open this folder in a terminal and run
  python -m http.server 8000
then open http://localhost:8000  (double-clicking index.html will not work: the curved gallery needs a server)
